## Burned-in captions removed

Four of the supplied files carried marketing copy baked into the image. The
text was removed by cropping, so no pixels were painted over or invented:

| Source | Phrase position | Crop applied |
|---|---|---|
| copper gown, archway | top left | trimmed 18.5% from the top |
| jewelry pendant | top left, over plain sky | trimmed 9.5% from the top |
| printed coat, blue backdrop | lower right | trimmed 18.5% from the bottom |
| green gown on dress form | lower right | kept the left 56.5%, gown only |

The originals are untouched in `/Users/es/Downloads/images`.

## Replacing or adding images

Drop files into `assets/img/` using the same filenames and the site picks them
up with no code changes. Sizes are listed in the main README. The original grey
SVG placeholders are kept in `assets/img/_placeholder-svg/`.
