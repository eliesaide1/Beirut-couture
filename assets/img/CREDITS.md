## What this means practically

* **Every file is now CC0** — public-domain dedicated. No credit required,
  commercial use fine, no obligations at all.
* The previous hero (a CC BY-SA documentary photograph of a tailoring
  workshop) was removed: wrong register for the brand, and the only file
  that carried an attribution obligation.

## Replacing them

Drop your own files into `assets/img/` using the same filenames and the site
picks them up with no code changes. Sizes are listed in the main README.
The original SVG placeholders are kept in `assets/img/_placeholder-svg/`.
